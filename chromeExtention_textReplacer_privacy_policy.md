# Privacy Policy for Text Replacer Chrome Extension

This extension does not collect, store, or transmit any personal data.

## What this extension does:
- It allows users to search and replace text within input and textarea elements on the currently active webpage.
- All operations are performed locally on the user's device.
- No data is sent to any external servers.

## Permissions
The extension uses the following permissions:
- **scripting**: To inject code into the current page for text manipulation.
- **activeTab**: To operate only on the user-selected tab.
- **host permissions**: To access `<input>` and `<textarea>` fields across websites.

## Data Handling
This extension does not collect or store:
- Personal data
- Usage data
- Browsing history
- Cookies

No information is transmitted off the user's device.

## Contact
For questions or support, please contact the developer via the Chrome Web Store support page.

# テキスト置き換え拡張 for Chrome 拡張機能のプライバシーポリシー

この拡張機能はいかなる個人情報も収集、保存、送信しません。

## この拡張機能がすること
- この拡張機能により、ユーザーは現在アクティブなウェブページ上の入力要素やテキストエリア要素内のテキストを検索し、置換することができます。
- すべての操作はユーザーのデバイス上でローカルに実行されます。
- 外部サーバにデータが送信されることはありません。

## Permissions
この拡張機能は以下のパーミッションを使用します：
- スクリプティング**： スクリプティング**: テキスト操作のために現在のページにコードを注入します。
- **activeTab**： ユーザが選択したタブに対してのみ操作します。
- ホストパーミッション**： ホストパーミッション**: `<input>` フィールドと `<textarea>` フィールドにアクセスします。

## Data Handling
この拡張機能は個人情報を収集したり保存したりしません：
- 個人データ
- 利用データ
- 閲覧履歴
- クッキー

ユーザーのデバイスから情報が送信されることはありません。

質問やサポートについては、Chrome ウェブストアのサポートページから開発者にお問い合わせください。
